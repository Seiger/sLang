# sLang Documentation

![sLang dictionary with three language columns](assets/images/slang-dictionary.png)

The Markdown in this branch is the source for both dDocs and the public site. dDocs reads these files and the manifest from the installed Composer package. The Docusaurus build on the `docs` branch reads the same files from each package branch.
